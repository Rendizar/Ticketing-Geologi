Fitur Setting Harga Tiket Dinamis

Museum Geologi Bandung - Ticketing System

Fitur Utama

  • Harga Tiket Dinamis

    Ubah harga tiket kapan saja melalui dashboard admin tanpa edit kode

  • Riwayat Perubahan Harga

    Semua perubahan harga tercatat lengkap dengan waktu, admin, dan alasan

  • Data Transaksi Aman

    Perubahan harga tidak menimpa data transaksi yang sudah ada

  • Tambah Kategori Baru

    Buat kategori tiket baru sesuai kebutuhan (VIP, Group, Promo, dll)

  • Aktif/Nonaktif Kategori

    Kontrol kategori mana yang ditampilkan di form pemesanan

  • Atur Urutan Tampilan

    Tentukan urutan kategori di halaman pemesanan

Routes yang Tersedia

Method URL Fungsi
GET /admin/settings/ticket-categories Daftar semua kategori tiket
GET /admin/settings/ticket-categories/create Form tambah kategori baru
POST /admin/settings/ticket-categories Simpan kategori baru
GET /admin/settings/ticket-categories/{id}/edit Form edit kategori
PUT /admin/settings/ticket-categories/{id} Update kategori
DELETE /admin/settings/ticket-categories/{id} Hapus kategori
GET /admin/settings/ticket-categories/{id}/history Lihat riwayat perubahan harga

Struktur Database

ticket_categories
  • id - Primary Key
  • name - Nama kategori (unique)
  • code - Kode kategori (unique)
  • price - Harga tiket (decimal)
  • description - Deskripsi
  • is_active - Status aktif (boolean)
  • sort_order - Urutan tampilan
  • timestamps - Created/Updated at
ticket_price_history
  • id - Primary Key
  • ticket_category_id - Foreign Key
  • old_price - Harga lama (decimal)
  • new_price - Harga baru (decimal)
  • changed_by - ID Admin
  • reason - Alasan perubahan
  • timestamps - Created/Updated at

Cara Setup

1. Jalankan Migration
php artisan migrate
2. Seed Data Awal (Opsional)
php artisan db:seed --class=TicketCategorySeeder
3. Akses Menu Setting
  • Login sebagai admin
  • Klik menu "Pengaturan Tiket" di sidebar
  • Mulai kelola kategori dan harga tiket
Info: Seeder akan membuat 3 kategori default: Pelajar (Rp 2.000), Umum (Rp 3.000), dan Wisatawan Asing (Rp 10.000)
